Entry: **History**

The whole internet in a single word. The internet never forgets — everything
posted becomes history: archived, screenshotted, searchable forever. And
everyone's browser history is the internet's oldest open secret. One word,
laugh then nod.

`entry/main.ts` writes exactly that word (7 characters, no trailing newline) to
`/output/entry.txt`, asserting the kit gate first (1–30 characters, single word,
not only whitespace) and verifying the read-back byte-for-byte.
